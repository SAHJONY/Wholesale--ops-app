# SAHJONY Deal-First Operating System

The owner application is organized around the work required to move a wholesale real-estate opportunity from source to assignment/closing.

## Primary operating spaces

1. Command — money, risk, approvals, next action.
2. Find Deals — Deal Factory, prospects, verification, property evidence.
3. Deal Room — real deals, underwriting, contracts and execution dossier.
4. Sellers — phone, conversations and supervised campaigns.
5. Buyers — buyer intake, proof-of-funds context and disposition.
6. Closing — title-company matching, assignment and closing checklist.
7. Control — action inbox and system health.

## Support surfaces

Markets, Data Sources, AI Workforce, Copilot, Integrations, Provider Activation, Audit, Security and Session Security remain available as administrative/support capabilities but are not primary deal navigation.

## Removed compatibility routes

- `/owner/activate`
- `/owner/nationwide-acquisition`

These were redirect-only compatibility surfaces and did not contain unique business capability.
