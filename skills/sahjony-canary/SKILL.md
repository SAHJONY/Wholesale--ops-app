# SAHJONY Canary
Observe frontend/backend commit parity, health/readiness, auth/session errors, route 4xx/5xx, background queue/retry/dead-letter, provider health, webhook failures, outbound blocked/sent counts, duplicate events, database latency, and critical page/API contract failures. Roll back or escalate immediately for tenant isolation, unauthorized dispatch, data corruption, or material revenue-accounting defects.
